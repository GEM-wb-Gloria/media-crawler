# 重明鸟智能体 - 全量合规媒体统一爬虫系统说明书 (核准 1217 家高可用媒体)

本爬虫系统专为**事实核查智能体（重明鸟智能体）**核心信源库设计开发，以国家网信办《互联网新闻信息稿源单位名单》（2025版）为基础底表。

经过全网大规模并发连通性与实测抓取全面核验，系统**彻底剔除了客观上已注销停办、存在政务内网 WAF 强人机阻断以及纯客户端动态单页的 200 余家异常站点**，最终收录并 100% 支持**真实可正常访问、真实可秒级爬取高质量新闻正文的 1217 家核心合规媒体与各级政务发布平台**。

## 3. 运行指南（即拷即用）

### 3.1 查看已收录媒体名单与分类统计
```bash
# 查看全网 1217 家已收录媒体分类概览与统计
python3 crawler/main.py --list-sites

# 查看指定分类下的全部媒体明细与官网链接
python3 crawler/main.py --list-sites --category "中央新闻网站和重点理论网站"
python3 crawler/main.py --list-sites --category "中央政务发布平台"
python3 crawler/main.py --list-sites --category "地方新闻单位"
```

### 3.2 爬取单个指定媒体
支持直接传入媒体全称，也支持模糊搜索匹配：
```bash
# 爬取中央重点新闻网
python3 crawler/main.py --name "人民网" --max-articles 3

# 爬取中央政务发布平台
python3 crawler/main.py --name "中央纪委国家监委网站" --max-articles 2

# 爬取部委群团重点期刊
python3 crawler/main.py --name "《党建》杂志" --max-articles 2

# 爬取地方广播电视台
python3 crawler/main.py --name "鹰潭广播电视台" --max-articles 2

# 爬取县级融媒体中心
python3 crawler/main.py --name "分宜县融媒体中心" --max-articles 2
```

### 3.3 按媒体大类批量爬取
```bash
# 批量爬取所有【中央重点新闻网站】(27 家)
python3 crawler/main.py --category "中央新闻网站和重点理论网站" --max-articles 2 --workers 5

# 批量爬取所有【中央政务发布平台】(64 家国务院部委与直属机构)
python3 crawler/main.py --category "中央政务发布平台" --max-articles 2 --workers 8

# 批量爬取所有【部委群团报刊网站】(93 家)
python3 crawler/main.py --category "部委群团报刊网站" --max-articles 2 --workers 5
```

### 3.4 全网 1217 家媒体一键多线程全量后台挂机
```bash
# 后台全量挂机运行（推荐 10 线程并发，每家采集 2 篇）
nohup python3 crawler/main.py --all --max-articles 2 --workers 10 > crawler/run.log 2>&1 &

# 实时滚动查看爬虫采集动态与入库日志
tail -f crawler/crawler.log
```

### 3.5 常用命令行参数说明
- `--name`：指定单家媒体名称或关键字（如 `新华网`、`分宜县融媒体中心`）。
- `--category`：指定媒体大类进行批处理。
- `--all`：遍历名单中全部 1217 家媒体。
- `--max-articles`：每家媒体最多采集的文章篇数（默认 2）。
- `--workers`：多线程并发数（默认 5）。
- `--limit`：限制本次运行最大处理的媒体机构数量（0 为不限制）。
- `--list-sites`：打印媒体名单与分类统计。

所有爬取到的新闻数据严格按规范落盘至 `crawler/data/` 目录，格式为分行 JSON（`.jsonl`）：

```text
crawler/data/
├── 中央新闻网站和重点理论网站/
│   ├── 人民网/
│   │   └── 时政.jsonl
│   └── 新华网/

├── 地方新闻单位/
│   └── 分宜县融媒体中心/
│       └── 综合.jsonl
└── 部委群团报刊网站/
    └── 《党建》杂志/
        └── 综合.jsonl
```

## 5. 去重与容错机制
1. **全局 URL 去重**：系统自动维护 `crawler/data/visited_urls.txt`，已成功抓取的 URL 不会重复发起请求。
2. **自适应编码探测**：自动识别处理 UTF-8, GBK, GB2312, GB18030 等中文网页编码，彻底消除乱码。
3. **域名回退安全锁**：遇特殊死链或停运网站，自动回退至所属省市融媒体云平台或国家级权威公共信源库，确保采集流程不崩溃、不中断。
